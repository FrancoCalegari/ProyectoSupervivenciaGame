# 🧟 SupervivenciaGame

## Documento del Sistema de Habilidades

### Versión
v0.1.1

---

# 1. Introducción

El sistema de habilidades permitirá que el jugador evolucione durante la supervivencia.

Cada acción realizada dentro del mundo podrá mejorar diferentes capacidades del personaje.

El objetivo es crear un sistema donde cada jugador pueda desarrollar su propio estilo de supervivencia.

---

# 2. Objetivos del Sistema

El sistema permitirá:

- Mejorar capacidades del jugador.
- Crear diferentes estilos de juego.
- Premiar la experiencia.
- Adaptarse a las decisiones del jugador.
- Crear progresión a largo plazo.

---

# 3. Sistema de Experiencia

El jugador obtendrá experiencia mediante acciones.

Ejemplos:

- Explorar zonas.
- Combatir enemigos.
- Construir estructuras.
- Reparar objetos.
- Ayudar NPC.
- Completar misiones.

---

# 4. Progreso del Jugador

El personaje podrá mejorar con el tiempo.

El progreso dependerá de:

- Acciones realizadas.
- Tiempo sobrevivido.
- Decisiones tomadas.
- Especialización elegida.

---

# 5. Categorías de Habilidades

Las habilidades estarán divididas en diferentes ramas.

---

# 6. Habilidades de Combate

Relacionadas con enfrentamientos.

Incluye:

- Manejo de armas.
- Precisión.
- Control del retroceso.
- Combate cuerpo a cuerpo.
- Uso táctico de armas.

Ejemplo:

↓

---

# 7. Habilidades de Supervivencia

Relacionadas con mantenerse vivo.

Incluye:

- Encontrar recursos.
- Administrar comida.
- Crear refugios.
- Resistir condiciones extremas.
- Adaptarse al entorno.

---

# 8. Habilidades de Construcción

Relacionadas con crear y mejorar bases.

Incluye:

- Construcción rápida.
- Mejores estructuras.
- Uso eficiente de materiales.
- Reparaciones avanzadas.

---

# 9. Habilidades de Reparación

Permiten mantener objetos.

Incluye:

- Reparación de armas.
- Reparación de vehículos.
- Reparación de herramientas.
- Creación de piezas.

---

# 10. Habilidades Médicas

Relacionadas con salud.

Incluye:

- Curación básica.
- Tratamientos avanzados.
- Uso eficiente de medicamentos.
- Atención de heridas.

---

# 11. Habilidades de Sigilo

Permiten evitar amenazas.

Incluye:

- Movimiento silencioso.
- Menor generación de ruido.
- Ocultamiento.
- Ataques sorpresa.

---

# 12. Habilidades de Exploración

Mejoran la capacidad de descubrir el mundo.

Incluye:

- Encontrar lugares ocultos.
- Detectar recursos.
- Crear rutas seguras.
- Interpretar mapas.
