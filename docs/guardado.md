# 🧟 SupervivenciaGame

## Documento del Sistema de Guardado

### Versión
v0.1.1

---

# 1. Introducción

El sistema de guardado permitirá conservar el progreso del jugador y el estado del mundo dentro de SupervivenciaGame.

El objetivo será que cada decisión, construcción, descubrimiento y avance permanezca registrado.

---

# 2. Objetivos del Sistema

El sistema permitirá:

- Guardar progreso del jugador.
- Mantener cambios del mundo.
- Evitar pérdida de información.
- Crear diferentes partidas.
- Preparar soporte futuro multijugador.

---

# 3. Tipos de Guardado

El juego tendrá diferentes métodos.

Incluye:

- Guardado manual.
- Autoguardado.
- Guardado por eventos.
- Guardado cooperativo futuro.

---

# 4. Guardado Manual

El jugador podrá guardar cuando quiera.

Permitirá almacenar:

- Ubicación actual.
- Inventario.
- Estado del personaje.
- Recursos.
- Construcciones.

---

Ejemplo:

Jugador entra al menú:

↓

Selecciona guardar partida.

↓

El sistema registra el progreso.

---

# 5. Autoguardado

El juego realizará guardados automáticos.

Momentos posibles:

- Descubrir una nueva zona.
- Completar una misión.
- Construir una base.
- Obtener un objeto importante.
- Cambiar de región.

---

# 6. Ranuras de Partida

El jugador podrá tener varias partidas.

Ejemplo:

## Partida 1

Superviviente principal.

---

## Partida 2

Modo desafío.

---

## Partida 3

Prueba de nuevas funciones.
