# 🧟 SupervivenciaGame

## Documento del Sistema de Inventario

### Versión
v0.1.1

---

# 1. Introducción

El sistema de inventario permitirá al jugador administrar todos los objetos necesarios para sobrevivir dentro del mundo de SupervivenciaGame.

El inventario estará diseñado buscando realismo, organización y toma de decisiones.

Cada objeto tendrá importancia dentro de la supervivencia.

---

# 2. Objetivos del Sistema

El sistema permitirá:

- Guardar objetos.
- Organizar recursos.
- Administrar peso.
- Equipar herramientas.
- Gestionar armas.
- Preparar equipamiento antes de una misión.

---

# 3. Mochila del Jugador

El jugador contará con una mochila para transportar objetos.

La capacidad dependerá de:

- Tipo de mochila.
- Peso transportado.
- Estado físico.
- Mejoras realizadas.

Ejemplo:

Mochila pequeña:

- Menor capacidad.
- Mayor movilidad.

Mochila grande:

- Mayor almacenamiento.
- Menor velocidad.

---

# 4. Sistema de Peso

Cada objeto tendrá un peso determinado.

El peso afectará:

- Velocidad de movimiento.
- Resistencia.
- Cansancio.
- Capacidad de combate.

Ejemplo:

Mucho peso:

↓

Menor movilidad.

↓

Mayor cansancio.
