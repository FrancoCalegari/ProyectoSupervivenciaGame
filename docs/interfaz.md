# 🧟 SupervivenciaGame

## Documento del Sistema de Interfaz

### Versión
v0.1.1

---

# 1. Introducción

El sistema de interfaz será el medio principal de comunicación entre el jugador y el mundo de SupervivenciaGame.

La interfaz deberá mostrar información importante sin romper la inmersión del jugador.

El objetivo será crear una experiencia clara, moderna y adaptable.

---

# 2. Objetivos del Sistema

La interfaz permitirá:

- Mostrar información del jugador.
- Facilitar la navegación.
- Mejorar la toma de decisiones.
- Mostrar peligros.
- Adaptarse a diferentes dispositivos.

---

# 3. Diseño General

La interfaz tendrá un diseño:

- Simple.
- Futurista.
- Realista.
- Inmersivo.
- Fácil de entender.

---

# 4. Menú Principal

El menú principal incluirá:

- Nueva partida.
- Continuar.
- Cargar partida.
- Multijugador.
- Opciones.
- Salir.

---

# 5. Pantalla de Inicio

Al iniciar el juego mostrará:

- Logo de SupervivenciaGame.
- Animación inicial.
- Música ambiental.
- Información de versión.

---

# 6. HUD Principal del Jugador

El HUD mostrará información durante la partida.

Incluye:

- Vida.
- Energía.
- Hambre.
- Sed.
- Temperatura.
- Estado del personaje.

---

# 7. Sistema de Vida

- Salud actual.

- Heridas.
- Estados críticos.
