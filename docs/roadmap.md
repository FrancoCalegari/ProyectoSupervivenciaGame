# 1. Visión del Proyecto

SupervivenciaGame es un videojuego de supervivencia postapocalíptico enfocado en una experiencia realista, dinámica e inmersiva.

El desarrollo se realizará mediante versiones y builds progresivas, agregando sistemas de forma organizada.
