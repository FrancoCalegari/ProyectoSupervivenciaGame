# 1. Introducción

El sistema de lanzamiento define la evolución de SupervivenciaGame desde sus primeras versiones hasta su versión final.

El objetivo es organizar el desarrollo, las pruebas y las futuras expansiones del proyecto.

- Sistemas principales documentados.
- Concepto de supervivencia.
- Diseño de combate.
- Sistemas de IA.
- Arquitectura del juego.
- Planificación futura.
