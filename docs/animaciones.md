# 🧟 SupervivenciaGame

## Documento del Sistema de Animaciones

### Versión
v0.1.1

---

# 1. Introducción

El sistema de animaciones será fundamental para crear una experiencia realista e inmersiva dentro de SupervivenciaGame.

Cada personaje, enemigo, NPC y objeto tendrá movimientos que representen correctamente sus acciones.

El objetivo será crear un mundo donde cada movimiento transmita vida y realismo.

---

# 2. Objetivos del Sistema

El sistema permitirá:

- Mejorar la inmersión del jugador.
- Crear movimientos realistas.
- Representar acciones de supervivencia.
- Mejorar el combate.
- Crear personajes más expresivos.

---

# 3. Animaciones del Jugador

El jugador tendrá diferentes tipos de movimientos.

Incluye:

- Caminar.
- Correr.
- Agacharse.
- Saltar.
- Escalar.
- Trepar.
- Nadar.
- Interactuar.

---

# 4. Movimiento Básico

Animaciones principales:

## Caminar

Características:

- Diferentes velocidades.
- Cambios según terreno.
- Variaciones por peso del inventario.

---

## Correr

Efectos:

- Mayor consumo de energía.
- Movimiento más rápido.
- Mayor ruido generado.

---

## Agacharse

Permitirá:

- Reducir ruido.
- Ocultarse.
- Mejorar sigilo.

---
